# Règles à respecter pour le nommage des branches 

## Conventions Git Flow à respecter :
```
    feature/description
    bugfix/description
    hotfix/description
    docs/description
    release/version
    develop
    main
```

Utilise uniquement des lettres minuscules, chiffres, tirets et underscores.


**Une Issue sera créée en cas de non-respect**
