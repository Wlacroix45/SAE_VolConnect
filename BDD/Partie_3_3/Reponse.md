## Réponse à la partie 3.3 

### Question 1

Les prédicats sont les faits stockés en base de données. Dans notre base de données déductives, il y a 3 prédicats :
- vol(IdVol, NomVol, NomCompagnie, AeroportDep, AeroportArr, VilleDep, PaysDepart, PaysArrivee, DateHeureDepart, DateHeureArrivee)
- employe(IdVol, NomEmploye, PosteEmploye)
- indiceQualite(idVol, nomIndice, Valeur, Poids)
